# Lessons

Create one directory per topic or curriculum.

Recommended starting files:

- `lesson.md` — the editable, audio-friendly source
- `transcript.txt` — generated spoken text
- `lesson.mp3` — generated narration

Optional additions:

- `curriculum.md` — a multi-lesson sequence and learning goals
- `sources.md` — references and verification notes
- `exercises.md` — active-recall questions or practice
- `assets/` — diagrams and other supporting material
- `chapters/` — separate source or audio files for a long course
